# Talmud — Mahloket

Prototype d’initiation au Talmud pour adolescents, avec un corpus annoté, une documentation éditoriale et des captures d’écran.

- [Application et instructions de lancement](app/README.md)
- [Documentation du projet](documentation/README.md)
- [Corpus et annotations](documentation/corpus/)
- [Captures d’écran](documentation/ecrans/)
- [Carnet Ayeka](Ayeka/Ouvrir%20le%20Talmud.html)

L’application fonctionne en mode démo sans clé API. Pour lancer le prototype :

```bash
cd app
npm install
npm run dev
```
